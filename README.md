# Nalbur Pro v0.3.2 — Mobile + Kodla e-Belge

Bu sürüm v0.3.1 Kodla e-Belge tabanını korur ve telefon kullanımını yeniden düzenler.

## Mobil iyileştirmeler
- Sabit alt mobil menü: Ana Sayfa, Satış, Stok, Cari, Diğer
- Hızlı Satış'ta ayrı Ürünler / Sepet sekmeleri
- Satış ekranı telefon yüksekliğine oturur; ana sayfa yerine ürün/sepet alanları kendi içinde kayar
- Sepet adedi mobil sekmede canlı görünür
- 2 sütun kompakt ürün kartları
- Ödeme butonları sepet görünümünde ekranda kalır
- Tablolar artık tüm sayfayı genişletmez; yalnızca tablo alanı yatay kayar
- Mobil form ve diyaloglar tam ekran çalışır
- Safe-area desteği ve 100dvh kullanımı eklendi
- Büyük dokunma hedefleri (minimum 44 px)

## e-Belge
Kodla adaptör mimarisi korunur. Gerçek gönderim için Kodla API/test servis bilgileri gerekir.
API anahtarları GitHub Pages içine eklenmemelidir.
